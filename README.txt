# AtlasLore Website

A responsive, mobile-friendly travel and destination discovery website.

## Files
- `index.html` — website structure
- `style.css` — responsive design and styling
- `script.js` — 50 destination records, search, filters, details modal, Google Maps links, and saved places

## Run on Android with Acode
1. Extract `AtlasLore-Website.zip` into a folder in your Documents or Downloads.
2. Open Acode and open the extracted folder (or open `index.html`).
3. Preview `index.html` using Acode's preview/browser option.
4. Keep `style.css` and `script.js` in the same folder as `index.html`.

## Publish free
You can upload the extracted project to GitHub Pages, Netlify, or Cloudflare Pages. Upload the three website files (or the project folder) and set `index.html` as the entry page.

## Notes
- Internet is needed for Google Fonts, remote Unsplash photos, and Google Maps links.
- Saved destinations are stored in the visitor's browser using localStorage.
- Destination history is concise introductory content. Verify current entry rules, opening hours, transport and safety information with official sources before travel.
